# CAD

The [Onshape headset assembly](https://cad.onshape.com/documents/7dd0dda11718de6338e637f2/w/5f67542aa0c734a01c21f813/e/294b57f9c610073ea687bedc) is the editable mechanical source. `headset-features.fs` is a copy of the custom feature definitions used in that document. The STEP files here are populated board references for fit work.

The headset preview shows an earlier CAD revision. The assembly in Onshape includes the later cable routing and battery connector shelf. Headband, pad, connector and harness fit still need to be checked on the physical build.
